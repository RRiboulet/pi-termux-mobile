# S0.8 — Phase 0 decision record

**Status: OPEN.** This is the document Phase 0 exists to produce. It is filled in from
measured evidence, not from opinion. Every cell either cites a spike report under
`docs/spikes/` or says "not measured".

**Reading a report.** Every report carries a `runId`, `startedAt`, `finishedAt` and a
`complete` flag, so a stale or partial run is distinguishable from a finished one. A
step marked `[exp]` in the text report is a step that was **supposed** to fail (the v3
control) and does not count towards `failedSteps`.

The plan's Phase 0 acceptance criterion is:

> [ ] S0.8 names the runtime, the env, the IPC transport and the security boundary,
>       and §1.6's `env` factory seam is fixed.

## 6. The security boundary

The plan's v1 decision is **trusted agent + accident guardrails + recoverable store**.
Not containment. Write down what that means concretely here, because "the agent is
trusted" is a claim that has to be earned by the controls, not asserted.

| Control | In place? | Where |
|---|---|---|
| Secrets never in the kernel's `process.env` | ☐ | Phase 1 |
| Every `exec` with `inheritEnv: false` | ☐ | Phase 1 |
| `git`/`gh` credentials per-command only, never in `.git/config` | ☐ | Phase 1 / R8 |
| `beforeTool` guard (`rm -rf`, `git push --force`, paths outside the workspace) | ☐ | Phase 4/5 |
| Curated exec by default; raw shell gated | ☐ | Phase 4/5 |
| Agent-written extensions are user-confirmed installs | ☐ | Phase 5 |
| Scheduled redacted SAF export | ☐ | Phase 1 skeleton, Phase 5 |
| The Pi DB is outside the workspace | ☐ | already true by construction |
| **Real uid boundary (separate worker APK)** | ☐ done ☐ deferred | **deferred**: a separate spike, not v1 |

**What is explicitly NOT a boundary, and must never be described as one:**

- `android:process=":kernel"` — process isolation, **not** a uid boundary.
- the `beforeTool` hook — a guardrail, **not** a sandbox. It sees command strings, not
  syscalls; `node -e`, `python -c`, `find -delete`, absolute paths and symlinks bypass
  a deny-list.
- proot — path translation, **not** a security boundary.
- `sharedUserId` — the same uid, and deprecated.
